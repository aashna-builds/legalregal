# Hugel Executive AI Kit

AI toolkit for Hugel executives, starting with contract review.

## Skills

### contract-review

Reviews contracts and agreements — distributor, HCP/practice, vendor, licensing, NDA, and other types — and flags risk areas using general pharma / medical device / aesthetics industry practice:

- Territory & exclusivity
- Minimum purchase commitments
- Product liability & indemnification
- IP / trademark licensing
- Regulatory compliance representations (FDA, off-label promotion, adverse event reporting)
- Confidentiality scope
- Termination
- Governing law

It auto-detects the type of agreement, asks clarifying questions when something is genuinely ambiguous, and always asks how you want the output delivered (quick chat answer vs. a written summary as a Word doc) before producing anything.

## Installation

Add this marketplace and install the plugin:

```
/plugin marketplace add <github-org-or-user>/hugel-executive-ai-kit
/plugin install hugel-executive-ai-kit@hugel-executive-ai-kit
```
